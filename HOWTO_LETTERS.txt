КАК САМОМУ ПИСАТЬ ПИСЬМА (два шаблона)
==========================================
Всё делается в одном файле news.json на github.com (Edit карандашом -> Commit).
Новое письмо = новый блок В НАЧАЛЕ списка, id всегда больше всех предыдущих.

--- ТИП 1: простое сообщение + поле для ответа ---
{
  "id": 9,
  "title": "Заголовок 💌",
  "text": "Текст сообщения здесь",
  "reply": true,
  "date": "2026-10-11"
}
reply:true = под сообщением появится поле "Написать ответ".
Без reply (или reply:false) = просто сообщение, ответить нельзя.

--- ТИП 2: сообщение + мини-письмо внутри + поле для ответа ---
{
  "id": 10,
  "title": "Заголовок ✨",
  "text": "",
  "miniText": "Длинный текст мини-письма здесь. Абзацы через пустую строку.",
  "reply": true,
  "date": "2026-10-11"
}
text пустой = обычного текста нет. Вместо кнопки "Прочитать" будет
"Открыть мини-письмо", по ней откроется окно с miniText.
Поле для ответа появится и в окне сообщения, и внутри мини-письма.

--- Правила ---
- id: каждый раз +1 от максимального (следующий будет 11, потом 12...).
  Сайт показывает баннер только если id больше уже виденных.
- date: любая подпись даты, формат свободный.
- Кавычки " внутри текста надо писать как \" иначе файл сломается.
- После Commit подождать 1-2 мин (GitHub Pages), новой ссылки НЕ надо:
  письмо само появится баннером + записью в инбоксе ✉️.
- Тот же текст продублируй пушем из OneSignal, чтобы долетело
  и на закрытый планшет (не забудь Launch URL со свежей ?v= ссылкой).

--- КУДА ПРИХОДЯТ ОТВЕТЫ И ГДЕ ИХ ВИДЕТЬ ---
Ответы хранятся в общей бесплатной базе Firebase и показываются ПРЯМО
В ТОМ ЖЕ сообщении (под полем ответа) — с любого устройства, просто
открыв сайт. Никакого Telegram не надо.

Настройка (1 раз, 5 минут, нужен твой Google-аккаунт):
1. Зайди на https://console.firebase.google.com -> Add project ->
   имя любое (напр. letter), Analytics можно выключить -> Create.
2. Слева Build -> Realtime Database -> Create Database ->
   регион europe-west1 -> Start in test mode -> Enable.
3. Вкладка Rules (Правила) -> замени всё этим и Publish:
   {
     "rules": {
       "replies": {
         "$msg": {
           ".read": true,
           "$rid": {
             ".write": "!data.exists() && newData.child('text').isString() && newData.child('text').val().length > 0 && newData.child('text').val().length <= 500",
             ".validate": "newData.hasChildren(['text', 'date'])"
           }
         }
       }
     }
   }
   Это значит: читать могут все, писать — только новые короткие ответы,
   менять и удалять чужое нельзя.
4. Project Overview (шестерёнка Project settings) -> вкладка General ->
   Your apps -> значок </> (Web) -> имя любое -> Register ->
   скопируй значения firebaseConfig: apiKey, authDomain, databaseURL, projectId.
5. На github.com открой config.json -> Edit -> вставь значения:
   {"firebase": {"apiKey": "...", "authDomain": "...",
    "databaseURL": "https://....firebasedatabase.app", "projectId": "..."}}
   Commit. Через 1-2 мин формы ответа и чужие ответы появятся на сайте сами.
6. Проверка: ответь сам с сайта -> обнови страницу -> ответ виден.
   С телефона/планшета тоже виден — база общая.

ВАЖНО ПРО БЕЗОПАСНОСТЬ: ключ Firebase виден в открытом коде — это нормально,
так задумано самим Firebase, защищают ПРАВИЛА выше, а не ключ. Но писать
в базу может любой, кто откроет сайт (спам возможен). Если пойдёт мусор —
временно закрой запись (".write": false), почисти данные во вкладке Data,
потом открой обратно. Письма (news.json) спамом не тронуть — они только
через твои коммиты.
