КАК ВКЛЮЧИТЬ ПУШ НА ЗАКРЫТЫЙ ПЛАНШЕТ (OneSignal, бесплатно)
============================================================

Что уже сделано в коде:
- message.json: меняешь title/text/version -> при следующем открытии сайта у неё вылезет баннер + модалка.
  Пока вкладка открыта, проверка идёт каждые 15 сек сама.
- Кнопка 🔔 на сайте: она жмёт 1 раз -> "Разрешить" -> системные уведомления на ЕЁ планшете включены.
- sw.js + OneSignalSDKWorker.js уже лежат в корне (так надо для пушей на GitHub Pages).

Но важно честно:
- Без внешнего push-сервиса пуш на ЗАКРЫТЫЙ планшет невозможен чисто статикой.
  Поэтому для "пришло даже когда закрыто" нужен OneSignal (ей НЕ надо регистрироваться,
  только 1 раз нажать "Разрешить" на сайте).

ШАГИ (5 минут, делаешь ты 1 раз):
1. Зайди на https://onesignal.com -> Sign Up (бесплатный план Free).
2. Add App -> Web -> Custom code.
   - Site URL: https://rayven-gi.github.io
   - Site path: /letter/
   - Permission prompt: bell + slide prompt (по умолчанию норм).
3. Скопируй APP ID вида xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.
4. На github.com открой свой репозиторий letter -> index.html -> Edit (карандаш):
   Найди строку: var ONESIGNAL_APP_ID = '';
   Вставь свой ID: var ONESIGNAL_APP_ID = 'твой-id';
   Commit changes.
5. Подожди 1-2 мин (GitHub Pages пересоберется).

КАК ПОЛЬЗОВАТЬСЯ:
- Ей: открыть https://rayven-gi.github.io/letter/?v=4 -> нажать 🔔 -> "Разрешить".
  На iPad (Safari): начиная с iOS 16.4 пуши приходят, только если сайт добавлен
  "Поделиться -> На экран Домой" и открыт как приложение. На Android-планшете работает сразу в Chrome.
- Тебе, чтобы прислать новое:
  a) На github.com отредактируй message.json: подними version на +1, поменяй title/text. Commit.
  b) Зайди в OneSignal -> Messages -> New Push -> заголовок+текст -> Send to All.
  Ей придёт системный пуш даже при закрытом планшете. Тап по пушу -> откроется сайт -> там баннер с тем же текстом.

БЕЗ OneSignal (прямо сейчас, без настроек):
- Просто правь message.json + кидай ей ссылку с новым ?v=5 в мессенджер.
  Она открывает -> видит баннер/модалку. Это уже работает из коробки.
