КАК ВКЛЮЧИТЬ ПУШ НА ЗАКРЫТЫЙ ПЛАНШЕТ (OneSignal, бесплатно)
============================================================

Что уже сделано в коде:
- news.json: лента ВСЕХ уведомлений (инбокс ✉️ на сайте читает её).
  Чтобы прислать новое: добавь в начало массива новый объект с id на +1 больше,
  поменяй title/text/date. Commit -> при следующем открытии сайта вылезет баннер +
  запись появится в инбоксе. Пока вкладка открыта, проверка идёт каждые 15 сек сама.
- Кнопка 🔔 на сайте: она жмёт 1 раз -> "Разрешить" -> системные уведомления на ЕЁ планшете включены.
- OneSignalSDKWorker.js лежит в /letter/ (код в index.html уже указывает serviceWorkerPath + scope /letter/).
  ВАЖНО: в кабинете OneSignal должны совпадать настройки воркера (см. шаг 2а ниже).

Но важно честно:
- Без внешнего push-сервиса пуш на ЗАКРЫТЫЙ планшет невозможен чисто статикой.
  Поэтому для "пришло даже когда закрыто" нужен OneSignal (ей НЕ надо регистрироваться,
  только 1 раз нажать "Разрешить" на сайте).

ШАГИ (5 минут, делаешь ты 1 раз):
1. Зайди на https://onesignal.com -> Sign Up (бесплатный план Free).
2. Add App -> Web.
   - Site URL: https://rayven-gi.github.io
2а. Про воркер (обязательно, иначе "couldn't find a subscription"):
    Если выбрал Custom Code: ничего в кабинете трогать не надо, путь уже прописан
    в index.html (serviceWorkerPath: letter/OneSignalSDKWorker.js, scope: /letter/).
    Если выбрал Typical Site:_code_ игнорируется, вместо этого иди в
    Settings -> Push & In-App -> Web -> Advanced Push Settings ->
    включи "Customize service worker paths and filenames" и введи:
      Path to service worker files: /letter/
      Service worker filename: OneSignalSDKWorker.js
      Registration scope: /letter/
    Мешать оба способа нельзя (либо код, либо кабинет).
3. Скопируй APP ID вида xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.
4. На github.com открой свой репозиторий letter -> index.html -> Edit (карандаш):
   Найди строку: var ONESIGNAL_APP_ID = '';
   Вставь свой ID: var ONESIGNAL_APP_ID = 'твой-id';
   Commit changes.
5. Подожди 1-2 мин (GitHub Pages пересоберется).

КАК ПОЛЬЗОВАТЬСЯ:
- Ей: открыть https://rayven-gi.github.io/letter/?v=4 -> нажать 🔔 -> "Разрешить".
  На iPad (Safari): начиная с iOS 16.4 пуши приходят, только если сайт добавлен
  "Поделиться -> На экран Домой" и открыт как приложение. На Android-планшете работает сразу в Chrome.
- Тебе, чтобы прислать новое:
  a) На github.com отредактируй news.json: добавь запись с новым id. Commit.
     (Тот же текст отправь и пушем ниже, чтобы совпадали.)
  b) Зайди в OneSignal -> Messages -> New Push -> заголовок+текст -> Send to All.
  Ей придёт системный пуш даже при закрытом планшете. Тап по пушу -> откроется сайт -> там баннер с тем же текстом.

БЕЗ OneSignal (прямо сейчас, без настроек):
- Просто правь news.json + кидай ей ссылку с новым ?v=8 в мессенджер.
  Она открывает -> видит баннер/модалку + запись в инбоксе ✉️. Это уже работает из коробки.
